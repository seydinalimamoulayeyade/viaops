🔍 01 · le problème test
// avant sonarqube
La code review humaine passe à côté de bugs subtils : code dupliqué, vulnérabilités, complexité cyclomatique élevée. Les tests unitaires ne suffisent pas — ils valident la logique, pas la qualité structurelle du code. SonarQube analyse statiquement le code et détecte bugs, code smells, failles de sécurité avant la production.
💡 Analogie
SonarQube est comme un scanner médical. Les tests unitaires vérifient que ton cœur bat, mais le scanner détecte les problèmes invisibles à l'œil nu : artères bouchées (code complexe), inflammation (duplication), tumeurs (vulnérabilités).
🧠 02 · concepts clés
// concepts sonarqube
ConceptDescription
BugErreur probable dans le code qui va causer un comportement incorrect en production.
VulnerabilityFaille de sécurité exploitable (injection SQL, XSS, secrets exposés).
Code SmellMauvaise pratique qui ne casse pas le code mais le rend difficile à maintenir (duplication, complexité).
Technical DebtTemps estimé pour corriger tous les code smells. Exprimé en jours/heures.
Quality GateSeuil de qualité minimum. Si le code ne passe pas, le build échoue.
CoveragePourcentage de code couvert par les tests. SonarQube ingère les rapports de coverage (JaCoCo, Istanbul).
// quality gate — exemple de règles
  • ▸Coverage > 80% — au moins 80% du code doit être testé.
  • ▸0 vulnerabilités critiques — aucune faille de sécurité majeure tolérée.
  • ▸Duplication < 3% — le code dupliqué ne doit pas dépasser 3%.
  • ▸Maintainability A/B — note de maintenabilité minimum B.

💼 05 · ce qu'il faut dire en entretien recruteur
// questions fréquentes · réponses attendues
▸ "Quelle différence entre un Bug et un Code Smell ?"
"Un Bug va causer un comportement incorrect en production. Un Code Smell est une mauvaise pratique qui rend le code difficile à maintenir, mais ne casse pas immédiatement."
▸ "C'est quoi un Quality Gate ?"
"C'est un seuil de qualité minimum — coverage, vulnérabilités, duplication. Si le code ne respecte pas ces critères, le build échoue et ne peut pas être déployé."
▸ "Comment SonarQube s'intègre dans le pipeline CI/CD ?"
"Après les tests unitaires, on lance sonar-scanner qui analyse le code et envoie les résultats à SonarQube. Ensuite, Jenkins vérifie le Quality Gate — si échoué, le pipeline s'arrête."
