📊 01 · le problème monitor
// avant prometheus & grafana
Ton app est en prod. Utilisateurs se plaignent de lenteur. CPU à 90% ? Mémoire leak ? Tu ne sais pas. Tu découvres les problèmes quand les utilisateurs râlent. Prometheus collecte les métriques en temps réel. Grafana les affiche. Tu vois les problèmes avant les utilisateurs.
💡 Analogie
Prometheus = capteurs médicaux (température, rythme cardiaque, pression). Grafana = le moniteur à l'hôpital qui affiche les courbes en temps réel. Si le cœur ralentit, l'alerte se déclenche avant l'arrêt cardiaque.
🧠 02 · concepts clés
// concepts prometheus
ConceptDescription
MétriqueDonnée numérique horodatée : CPU, RAM, nombre de requêtes HTTP, latence.
ScrapingPrometheus interroge (pull) les services toutes les X secondes via HTTP /metrics.
Time SeriesSéquence de valeurs dans le temps. Ex: cpu_usage{instance="api"} = [45, 47, 52, 89...].
PromQLLangage de requête pour interroger les métriques. Ex: rate(http_requests[5m]).
ExporterService qui expose des métriques au format Prometheus (/metrics endpoint).
AlertmanagerGère les alertes : déduplique, route, envoie vers Slack, email, PagerDuty.
// types de métriques
  • ▸Counter : compteur qui ne fait qu'augmenter (nombre de requêtes, erreurs).
  • ▸Gauge : valeur qui monte et descend (CPU, RAM, température).
  • ▸Histogram : distribution de valeurs (latence p50, p95, p99).
  • ▸Summary : comme histogram mais avec calcul côté client.
⌨️ 03 · commandes de référence
// prometheus.yml — configuration
yaml prometheus config 
global:
  scrape_interval: 15s  # Scraper toutes les 15s

scrape_configs:
  - job_name: 'node-exporter'
    static_configs:
      - targets: ['localhost:9100']

  - job_name: 'api'
    static_configs:
      - targets: ['api:3000']
    metrics_path: '/metrics'

alerting:
  alertmanagers:
    - static_configs:
        - targets: ['alertmanager:9093']

// promql — requêtes essentielles
promql requêtes de base 
# CPU usage moyen
avg(rate(cpu_usage[5m]))

# Nombre de requêtes HTTP par seconde
rate(http_requests_total[1m])

# Latence p95 (95e percentile)
histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m]))

# Taux d'erreur 5xx
sum(rate(http_requests_total{status=~"5.."}[5m]))

# Mémoire disponible par instance
node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes * 100

💼 05 · ce qu'il faut dire en entretien recruteur
// questions fréquentes · réponses attendues
▸ "Quelle différence entre Prometheus et Grafana ?"
"Prometheus collecte et stocke les métriques en time series. Grafana se connecte à Prometheus et affiche les dashboards avec des graphiques. Prometheus = backend, Grafana = frontend."
▸ "C'est quoi un Exporter ?"
"Un service qui expose des métriques au format Prometheus via un endpoint HTTP /metrics. Exemple : node_exporter pour les métriques système (CPU, RAM, disque)."
▸ "Comment configurer une alerte dans Prometheus ?"
"On écrit des règles d'alerte en PromQL dans un fichier de config. Si la condition est remplie, Prometheus envoie l'alerte à Alertmanager qui la route vers Slack, email ou PagerDuty."
